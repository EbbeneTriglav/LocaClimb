# LocaRide v2 (beta) - https://locaride.app/v2/

Nuova interfaccia "Notturna + Road book" (stile A+C dei concept del 29/10/2026), in parallelo
all'app classica: stessi dati, nessuna modifica all'app di oggi.

| Schermata | Cosa fa |
|---|---|
| **Mappa** | Mappa scura con rilievo (bottone 3D), salite come punti luminosi colorati per difficoltà, filtri (Dure 8+, 10/10, Scoperte), elenco delle salite inquadrate, ricerca |
| **Salita** `#/s/<id>` | Volo 3D sulla salita colorata per pendenza, numeri chiave, verdetto meteo in cima con fascia 7-19, profilo, road book km per km (km più duro in giallo), GPX |
| **Modalità salita** | Schermo per il manubrio: km e metri alla cima, pendenza del prossimo km, dal GPS (cursore per provarla a casa) |
| **Oggi** `#/oggi` | Le 12 salite più dure entro 60 km (GPS o centro mappa), ordinate per meteo in cima, oggi / domani / dopodomani |
| **Diario** `#/diario` | Le tue salite reali (da GPX/FIT/zip importati nell'app classica) con i record; accesso Google condiviso con l'app classica |

Fonti: OpenFreeMap (mappa base), AWS Terrain Tiles (rilievo), Open-Meteo (meteo), dati LocaRide.
Codice: `v2/` (vedi CLAUDE.md, sezione v2). Test: `node --test test/v2-lib.test.mjs`.
